MODULE 01 // DSP

核心重采样引擎

基于现代 C++ / Python 构建的数字信号处理（DSP）声学流水线，实现毫秒级相位声码器与多音阶频域重构。

• 32-Bit Float 高精度音频缓冲区 • SIMD 指令集加速渲染
MODULE 02 // PROTOCOL

宿主与规范兼容

全方位适配 UTAU 经典规范与新一代 OpenUTAU 引擎标准，支持原生 oto.ini 映射与连续音包络解析。

• 标准命令行 Resampler IPC 通信 • 音高曲线 (Pitch Bend) 动态插值
MODULE 03 // FULLSTACK

现代 Web 平台

轻量原生单页应用（SPA）前端架构搭配 Node.js / SQLite 高并发后端，集成 Cloudflare Turnstile 安全网关。

• 零打包工具依赖，极速毫秒加载 • RESTful 架构 + 密码学 SHA-256
